# 🔗 دليل ربط Neo Pulse Hub مع Manus API

هذا الدليل يشرح كيف يمكنك استخدام **Manus** كعقل مدبر لمنصتك للقيام بمهام الأتمتة الصعبة تلقائياً.

## 1. الحصول على مفتاح API
1. اذهب إلى إعدادات حسابك في [Manus.ai](https://manus.ai).
2. ابحث عن قسم **API Keys**.
3. قم بإنشاء مفتاح جديد واحفظه في مكان آمن.

## 2. إعداد متغيرات البيئة
يجب إضافة المفتاح في منصة الاستضافة الخاصة بك (مثل Render أو GitHub Secrets) بالاسم التالي:
`MANUS_API_KEY=your_key_here`

## 3. كيفية عمل التكامل (Task Lifecycle)
الربط يعتمد على دورة حياة المهمة:
1. **إنشاء المهمة (Create Task):** يرسل خادمك طلباً لـ Manus يحتوي على الهدف (مثلاً: "حدث المتجر").
2. **التنفيذ (Execution):** يبدأ Manus بالعمل بشكل مستقل (البحث، البرمجة، الكتابة).
3. **استلام النتائج (Results):** يمكنك استلام النتائج إما عن طريق الفحص الدوري (Polling) أو عن طريق **Webhooks** (الخيار الأفضل للإنتاج).

## 4. المهام المؤتمتة الحالية
لقد قمت ببرمجة سكربت `backend/manus_daily_updater.py` الذي يطلب من Manus:
- البحث عن منتجات جديدة.
- تحديث قاعدة البيانات والصور.
- كتابة مقالات للمدونة.
- رفع التحديثات لـ GitHub.

## 5. تطوير الربط (Webhooks)
لجعل الربط احترافياً 100%، يفضل تفعيل الـ Webhooks في Manus لإرسال إشعار لمنصتك فور انتهاء المهمة. يمكنك ضبط رابط الـ Webhook الخاص بك في إعدادات المهمة عبر الـ API.
