# خطة النمو العالمية كل 6 ساعات

## الهدف

تعمل منصة **Neo Pulse Hub** على دورة نمو دورية كل ست ساعات عبر مجدول الخادم الموجود في Render. تنفذ الدورة تحديثات قابلة للتكرار، وتدقيقاً للكتالوج، وتوليد مسودات حملات متعددة اللغات، ثم ترسل إلى Manus مهمة تحليل منظمة عند توفر `MANUS_API_KEY`.

## جدول الدورة

| المرحلة | ما يحدث | النتيجة |
|---|---|---|
| بداية الدورة | تحديث المتجر الموجود عبر `supplier_bot` | فحص وإضافة المنتجات وفق منطق المنصة الحالي |
| تدقيق الكتالوج | حساب عدد المنتجات، الصور الفريدة، الصور المكررة، والفئات | تقرير `latest_catalog_audit.json` |
| الحملات | اختيار أفضل ثلاثة منتجات حسب التقييم والمراجعات | مسودات عربية وإنجليزية لـ Instagram وTikTok وTelegram والبريد الإلكتروني |
| تحليل Manus | إرسال ملخص الكتالوج إلى Manus بمخرجات JSON منظمة | أولويات نمو، زوايا حملات، اقتراحات SEO، وملاحظات مخاطر |
| الحفظ | حفظ حالة مهمة Manus والنتيجة الأخيرة | إمكانية متابعة المهمة في الدورة اللاحقة |

## سياسة النشر والحماية

لا تنشر الدورة إعلانات مدفوعة، ولا ترسل رسائل جماعية، ولا تنفذ عمليات شراء أو تغييرات حساسة تلقائياً. تظل مسودات الحملات بحالة `draft` وتحتاج إلى مراجعة بشرية أو ربط موصل رسمي للمنصة المطلوبة قبل النشر. هذا يمنع نشر محتوى غير مُراجع أو استهلاك ميزانية إعلانية دون موافقة صريحة.

## متغيرات البيئة

يحتاج الخادم إلى المتغير التالي لتفعيل تحليل Manus:

```text
MANUS_API_KEY=ضع المفتاح في Render Environment Variables فقط
```

لا يجب وضع المفتاح داخل GitHub أو ملفات المشروع. إذا تم نشر المفتاح في محادثة أو ملف عام، يجب إلغاؤه وإنشاء مفتاح بديل فوراً.

## مهام التطوير اللاحقة

ينبغي ربط كل منصة اجتماعية عبر موصل رسمي منفصل قبل السماح بالنشر التلقائي. كما ينبغي استبدال الصور المكررة بصور مرخصة أو أصول أصلية حقيقية لكل منتج؛ دورة النمو الحالية ترصد التكرار بدقة لكنها لا تخفيه باستخدام روابط placeholder مكررة.

## الملفات

- `backend/global_growth_cycle.py`: محرك دورة النمو.
- `backend/main.py`: يستدعي المحرك من مجدول Render كل ست ساعات.
- `docs/reports/growth/latest_catalog_audit.json`: تقرير تدقيق الكتالوج الناتج أثناء التشغيل.
- `data/six_hour_campaigns.json`: مسودات الحملات الناتجة أثناء التشغيل.
- `data/manus_growth_tasks.json`: حالة مهام Manus والنتائج المنظمة.
