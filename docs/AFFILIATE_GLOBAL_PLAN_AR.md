# خطة Neo Pulse Hub العالمية للعمولة

## الفكرة الصحيحة

لا ينبغي أن يدّعي Neo Pulse Hub أنه يبيع مخزون جميع الشركات العالمية أو يمثلها. النموذج القانوني والقابل للتوسع هو **منصة اكتشاف ومقارنة وتوصية**: تعرض منتجات من شركاء معتمدين، ثم تنقل المستخدم إلى متجر الشريك عبر رابط تتبع affiliate/deep link. الدفع، الشحن، الضمان، الإرجاع وخدمة العملاء تبقى لدى الشريك ما لم توجد اتفاقية بيع منفصلة.

لا نضيف منتجًا أو سعرًا أو نسبة عمولة من التخمين. كل سجل يجب أن يحمل المصدر، والبلد، والعملة، ووقت آخر تحقق، ورابط التتبع، وحالة البرنامج.

## ترتيب الإطلاق المقترح

### المرحلة الأولى: 3 مصادر فقط

1. **Amazon Associates** للأسواق التي تناسب الجمهور، مثل Amazon.ae وAmazon.sa وإسبانيا وغيرها من الأسواق المتاحة. نستخدم Special Links أو deep links، ولا نفترض قبول الحساب أو ثبات العمولة. الوصول إلى Product Advertising API مرتبط بأهلية الحساب وشروط Amazon.
2. **eBay Partner Network** للمنتجات والعروض التي يصعب توفيرها في متجر واحد. يمكن البدء بروابط عميقة، ثم استخدام Browse/Feed/Marketing/Deal APIs بعد الموافقة والصلاحيات.
3. **Awin أو impact.com** للوصول إلى علامات ومتاجر متعددة. نختار شبكة واحدة في البداية ونختبرها على فئة تقنية محددة بدل دمج شبكات كثيرة دفعة واحدة.

### المرحلة الثانية

بعد قياس النقرات والطلبات المؤهلة، نضيف Rakuten Advertising وCJ Affiliate وAliExpress Affiliate Program، مع فحص كل برنامج ومعلن على حدة. وجود الشبكة لا يعني أن كل علامة أو بلد أو منتج متاح تلقائيًا.

## كيف يعمل النظام

1. يستقبل النظام feed أو API رسميًا من الشريك.
2. يحوّل الحقول إلى نموذج موحد: الاسم، الفئة، الصورة، السعر، العملة، البلد، حالة التوفر، المتجر، الرابط الأصلي، رابط التتبع، وقت التحديث ومصدر البيانات.
3. يزيل التكرار دون دمج منتجات مختلفة بالخطأ.
4. يختار الرابط حسب بلد المستخدم والعملة واللغة.
5. يعرض صفحة مقارنة أو مراجعة أصلية، لا مجرد نسخ وصف الشريك.
6. يسجل النقرات والطلبات المؤهلة في لوحة تحليلات دون تخزين بيانات دفع العملاء.
7. يوقف المنتج تلقائيًا عند انتهاء الرابط أو توقف البرنامج أو قدم السعر.

## نموذج بيانات مقترح

```json
{
  "id": "source-product-id",
  "merchant": "approved-merchant",
  "network": "amazon|ebay|awin|impact|rakuten|cj|aliexpress",
  "market": "ES|SA|AE|US",
  "currency": "EUR",
  "source_url": "https://merchant.example/product",
  "affiliate_url": "https://tracking.example/deep-link",
  "price": null,
  "availability": "unknown",
  "last_verified_at": null,
  "commission_status": "not_disclosed",
  "disclosure_required": true,
  "status": "pending_approval"
}
```

لا يجوز نشر سجل بحالة `approved` قبل وجود موافقة البرنامج والتحقق من الرابط والبلد والسعر.

## مصادر العمولة التي تم التحقق من وجودها

- Amazon: التسجيل والاتفاقية وسياسات التشغيل والعمولات تختلف حسب السوق والفئة. لا نعرض نسبة عامة ثابتة.
- eBay Partner Network: روابط عميقة وواجهات Browse/Feed/Marketing/Deal بعد التسجيل والصلاحيات. المعدل يختلف حسب السوق والفئة.
- Awin: شبكة أداء تدعم deep links وproduct feeds وواجهات API، والعمولة يحددها كل معلن وبرنامج.
- CJ Affiliate: برامج معلنين وروابط عميقة وواجهات ومنتجات، مع قبول منفصل وشروط كل معلن.
- impact.com: برامج وعلامات وكتالوجات وروابط عميقة وواجهات، مع أهلية منفصلة لكل برنامج.
- Rakuten Advertising: Product Search API وProduct Catalog وDeep Links API، ولا يعمل الرابط العميق إذا لم يكن الناشر شريكًا للمعلن.
- AliExpress Affiliate Program: روابط وواجهات للمنتجات والطلبات، لكن المعدلات التسويقية المعروضة هي حدود أو عروض متغيرة وليست ضمانًا لكل منتج.

## قواعد مالية وتسويقية

- لا نعد المستخدم بخصم أو سعر ثابت إذا لم يؤكده الشريك لحظة النقر.
- لا نكتب أن Neo Pulse Hub يملك أو يمثل Amazon أو eBay أو أي علامة دون اتفاقية.
- نضع إفصاحًا واضحًا بجانب زر الشراء: **قد يحصل Neo Pulse Hub على عمولة عند إتمام شراء مؤهل عبر الرابط**.
- لا نستخدم إعلانات مدفوعة ترسل المستخدم مباشرة إلى الشريك إذا كانت شروط البرنامج تمنع ذلك.
- لا نستخدم brand bidding أو أسماء العلامات في الإعلانات إلا بعد فحص شروط البرنامج.
- لا نستخدم cookie stuffing أو النوافذ المضللة أو النقرات القسرية أو التقييمات المزيفة.
- لا نخزن بيانات البطاقة أو الدفع؛ تتم المعاملة لدى الشريك.
- نلتزم بالخصوصية وGDPR وحقوق الصور والوصف، ونحذف المنتج عند انتهاء الترخيص أو الرابط.

## أفضل نموذج ربح للبداية

ابدأ بفئة واحدة: **أجهزة العمل والمنزل الذكي**. أنشئ صفحات مقارنة أصلية باللغة العربية والإسبانية والإنجليزية، مثل:

- أفضل سماعات للعمل والاجتماعات.
- أجهزة منزل ذكي مناسبة للسكن في إسبانيا.
- مقارنة ساعات اللياقة حسب السعر والبطارية.
- معدات مكتب منزلي أقل من ميزانية محددة.

كل صفحة يجب أن تعرض ثلاثة إلى ستة خيارات موثقة، وتذكر المتجر والعملة وتاريخ تحديث السعر. لا نبدأ بمئات العلامات؛ نبدأ بـ 30 إلى 50 منتجًا عالي الجودة من برامج مقبولة، ثم نوسع بعد قياس النقرات والتحويلات.

## مؤشرات النجاح

- نسبة النقر على رابط الشريك.
- نسبة النقر الذي يتحول إلى طلب مؤهل.
- قيمة العمولة لكل صفحة وفئة وبلد.
- نسبة الروابط المنتهية أو الأسعار القديمة.
- نسبة المنتجات التي تم رفضها من البرنامج.
- تكلفة جلب الزيارة مقارنة بالعمولة الفعلية.
- نسبة المستخدمين العائدين والاشتراك في التنبيهات.

لا نعتبر عدد المنتجات مؤشر نجاح رئيسيًا؛ جودة الرابط، حداثة السعر، وثقة المستخدم أهم.

## الخطوة البرمجية التالية

قبل إضافة أي API تجاري، يجب إنشاء:

1. جدول `affiliate_sources` للشبكات والبرامج وحالة الموافقة.
2. جدول `affiliate_products` مع `network`, `merchant`, `market`, `currency`, `source_url`, `affiliate_url`, `last_verified_at`.
3. عامل مزامنة دوري لا يكتب إلا المنتجات القادمة من مصدر معتمد.
4. صفحة إفصاح وخصوصية وشروط استخدام.
5. لوحة روابط منتهية وفشل التتبع.
6. اختبارات تمنع إدراج `affiliate_url` غير موثوق أو منتج بلا مصدر.

لن يتم تفعيل أي مصدر تجاري فعلي أو إدخال مفاتيح API حتى يتم قبول Neo Pulse Hub في البرنامج المعني وإضافة الأسرار عبر إعدادات الاستضافة، لا داخل Git.
