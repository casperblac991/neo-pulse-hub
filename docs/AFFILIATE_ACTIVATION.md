# تفعيل العمولة في Neo Pulse Hub

تم تجهيز الكود لاستقبال بيانات العمولة بأمان، لكن لا يتم تفعيل أي شبكة قبل قبول الحساب والبرنامج. لا توجد مفاتيح حقيقية داخل المستودع.

## ما هو جاهز الآن

- سجل لسبع شبكات عمولة.
- `GET /api/affiliate/programs` لعرض الشبكات والأسواق والإفصاح.
- `GET /api/affiliate/status` لعرض وجود الإعدادات دون كشف قيمها.
- `scripts/affiliate-readiness.mjs` لفحص متغيرات البيئة محليًا.
- اختبارات تمنع إنشاء روابط قبل الموافقة أو باستخدام روابط غير آمنة.
- إفصاح ظاهر في صفحة المنتجات.
- حقول Render جاهزة لمتغيرات الشبكات.

## تفعيل شبكة بعد الموافقة

بعد قبول شبكة وبرنامج معلن محدد، أضف متغيراته في Render Environment. لا تضفها إلى GitHub. ثم اضبط:

```text
AFFILIATE_APPROVED_NETWORKS=amazon-associates
```

يمكن وضع أكثر من شبكة مفصولة بفاصلة، لكن لا تفعل ذلك إلا بعد القبول الحقيقي:

```text
AFFILIATE_APPROVED_NETWORKS=amazon-associates,awin
```

وجود متغيرات الاعتماد وحده لا يفعّل الشبكة. هذا مقصود لمنع نشر روابط غير قانونية أو غير قابلة للإسناد.

## الفحص

```bash
node scripts/affiliate-readiness.mjs
```

الفحص يعرض أسماء المتغيرات الناقصة فقط ولا يعرض أي قيمة سرية، ولا يتصل بمزود خارجي.

بعد حفظ متغيرات Render، أعد النشر ثم اختبر:

```bash
curl https://neo-pulse-hub.onrender.com/api/affiliate/status
curl https://neo-pulse-hub.onrender.com/api/affiliate/programs
```

## المرحلة التي تحتاج اعتمادًا فعليًا

لكل شبكة موصل رسمي مستقل، لأن Amazon PA-API وAwin وeBay وغيرها تختلف في التوقيع، الصلاحيات، الأسواق، القيود ومخطط البيانات. لا ينبغي استخدام رابط تتبع مخمّن أو معلمات غير موثقة. عند توفر موافقة الشبكة وبيانات API الرسمية، يضاف الموصل في وضع read-only أولًا لجلب خمسة منتجات فقط، ثم تتم مراجعة السعر والصورة والتوفر والرابط، وبعدها تفعّل المزامنة الدورية.

## لا يتم تنفيذه آليًا

- إنشاء حساب ببيانات هوية أو ضرائب غير معروفة.
- قبول اتفاقيات الشركاء نيابة عن صاحب الحساب.
- إدخال مفاتيح API غير مقدمة من لوحة الشبكة.
- تفعيل عمولة أو إعلان قبل الموافقة.
- نشر أسعار أو صور دون مصدر وترخيص.
